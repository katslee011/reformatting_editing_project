Summary of Changes: Document 1

For my first document, I chose to reformat and edit an essay I wrote about the discourse of classical clarinetists. I chose this document because I wanted to format a document with a visual, which lets me practice writing alt text. To format this document, I used Markdown.

List of Changes

  • Added subheadings
  • Broke up paragraphs
  • Formatted text italicized in original document
  • Corrected link formatting for citations
  • Added alt text to image
  • Changed "Discourse" to "discourse"
  • Improved parallelism in introduction paragraph
  • Improved explanations of technical terms

Explanation of Changes

I originally wrote this document in Google Docs, so to move it to GitHub, I copy-and-pasted the text into a Markdown file. When I did so, I removed the original document's formatting, which included italics. Additionally, because I'd originally written it as a double-spaced, indented document, the paragraphs that were readable in the original context became unreadable in its new, single-spaced context. To address these changes, I broke the essay up into different sections (indicated by subheadings), broke up the essay into smaller paragraphs, and re-added the formatting lost by the migration process.

After cleaning up the document, I decided to take advantage of some of Markdown's features to make the essay more reader friendly. I made the citations' URLs hyperlinks so that readers could access the sources easier, and then I added alt text to the image for improved accessibility.

Finally, I took the time to polish the content of the document. In the original essay, I had capitalized "Discourse," which wasn't correct, as "discourse" isn't a proper noun. Other than small grammatical changes like that, I noticed that my original essay's explanation of technical terms (like its explanation of clarinet reeds) was choppy and difficult to understand. I'd originally written this essay to be read by an audience that isn't familiar with clarinets or clarinetits, so I knew I needed better explanations of the technical terms. To improve the explanations, I adjusted the sentence structure, separated the explanations into their own sentences, and expanded the explanations.
