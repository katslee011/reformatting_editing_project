Summary of Changes: Document 2

For my second document, I chose to work on a how-to article I created for WRIT 3562W: Technical & Professional Writing. I created this document with a group of two other people, and I contributed to some of the text, research, and created all the images.

List of Changes

  • Differentiated list hierarchies with type attribute
  • Resized images with CSS
  • Labeled sections using semantic HTML
  • Added underlines to instructions for pen and eraser
  • Added alt text to images
  • Bolded text in "Caution" section
  • Removed semicolon in "Caution" section

Explanation of Changes

This document was originally created in Google Docs. HTML is a fairly extensive language, so I had to copy-and-paste the document in chunks, paying careful attention to what tags I put each block of text under. Reformatting this document with HTML also presented me with a unique challange. When creating lists-inside-lists in Google Docs, Docs automatically differentiates the parent list with numbers and the child list with letters. HTML does not do this automatically. To re-add this feature to the HTML document, I had to use the type attribute. Additionally, the original document included colored text. While I could have added the color to the HTML text directly using the style attribute, I decided not to. Instead, I used CSS and the class attribute. Finally, because the images were originally very large (4096 px x 4096 px) I had to resize the images, which I also used CSS to do.

HTML has several accessibility features. One such feature is semantic HTML, which let me label the sections of my document for screen-readers to identify. Another feature is alt text, which I carefully wrote up, considering both context (what's important about this image?) and conciseness (what isn't important about this image?). Finally, in the original document, my group and I decided to use colored text to indicate which steps need pen and which need eraser. However, I worried this wasn't colorblind friendly, so when I reformatted this document for this project, I used CSS to add underlines to the different types of text, a wavy underline for pen instructions and a dotted underline for eraser instructions.

Because this document is more recent (created last semester, Fall 2025), I didn't have many edits beyond the ones I did for HTML. However, I did add some small changes to the "Caution" section. I changed it from a single, compound sentence (combined with a semicolon) to two simple sentences to make it more readable. Additionally, I bolded the first sentence, because I wanted to make it clear what, exactly, the Caution section is advising its readers to do.
